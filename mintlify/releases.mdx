title: "Beta release notes"
description: "Scope and observed validation."

The local beta includes npm monitoring and Settings, the native VS Code workflow, Elf Bridge, and local stdio MCP. Hosted MCP and web-only assistant connectors are deferred.

Live acceptance on macOS confirmed managed-resource drift ownership, individual review, real watcher-driven updates, stable master identity, and restored source/node hashes. Automated regression suites cover stale reviews and connection changes.

Windows/Linux and Node 20 matrix jobs were not executed because GitHub Actions was blocked by the repository account’s billing status. A local test directory is not proof of a fresh-machine or cross-platform pass.

Public npm, Marketplace, and Figma Community listings are separate release steps. Install only releases announced by the project. The npm beta `elf-tokens@1.0.0-beta.1` was uploaded on October 31, 2026. Public registry availability is still being verified; do not assume the beta command works until the version and `beta` tag resolve. Figma Community and VS Code Marketplace submissions remain separate.


Elf Bridge’s Community submission was not approved. The documented setup currently uses a development manifest in Figma Desktop while review requirements are clarified. Existing functionality is preserved; this installation method is not a statement of policy approval.


The Elf VS Code extension is available at its [official Marketplace listing](https://marketplace.visualstudio.com/items?itemName=NonsoOnah.elf-design-system). Select the pre-release version for the beta. Figma Community approval is separate and remains unresolved.
