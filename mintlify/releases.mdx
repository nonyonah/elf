---
title: "Beta release notes"
description: "Scope and observed validation."
---

The local beta includes npm monitoring and Settings, the native VS Code workflow, Elf Bridge, and local stdio MCP. Hosted MCP and web-only assistant connectors are deferred.

Live acceptance on macOS confirmed managed-resource drift ownership, individual review, real watcher-driven updates, stable master identity, and restored source/node hashes. Automated regression suites cover stale reviews and connection changes.

Windows/Linux and Node 20 matrix jobs were not executed because GitHub Actions was blocked by the repository account’s billing status. A local test directory is not proof of a fresh-machine or cross-platform pass.

Public npm, Marketplace, and Figma Community listings are separate release steps. Install only releases announced by the project. The intended npm release is `1.0.0-beta.1`; confirm availability before using the quickstart command.
