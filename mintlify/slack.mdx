---
title: "Slack notifications"
description: "Receive drift changes in your chosen channel."
---

Open Manage or Settings, select **Connect Slack**, authorize Elf, and choose the notification channel. You should not need to create a Slack app or paste a webhook URL.

Configure notification preferences and use the explicit test action when you want to send a test message. Workspace administrators may need to approve installation.

Drift notifications report detected changes; unchanged repeated checks should not produce repeated alerts. Review the report for complete context. Disconnect Slack from the same connection controls when you want to stop delivery.

Slack delivery is a notification feature. It does not execute tests or replace local release validation.
