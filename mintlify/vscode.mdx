---
title: "VS Code extension"
description: "Use Elf from the native editor sidebar."
---

The extension provides **Overview**, **Changes**, and **Activity**. Use **Manage** for connections, pairing, notification preferences, automatic sync, and coding-assistant setup.

Install [Elf from the Visual Studio Marketplace](https://marketplace.visualstudio.com/items?itemName=NonsoOnah.elf-design-system). Choose the pre-release version for the current beta. The extension ID is **NonsoOnah.elf-design-system**.

Alternatively, install from your terminal:

```sh
code --install-extension NonsoOnah.elf-design-system --pre-release
```

Reload VS Code, open a trusted local project, then select the Elf activity-bar icon and Start. For a maintainer-provided VSIX, use **Extensions → … → Install from VSIX**.

Install Elf Bridge using its [development manifest in Figma Desktop](/pairing). This setup requires the desktop app; it is not a Community installation.

The extension bundles the shared Elf runtime. npm remains supported; you do not need to clone the repository to use a published build. Figma and Slack authorization can open a browser.

Select an individual drift to inspect that resource. Use component review actions to prepare descriptions and review supported sync changes. AI descriptions depend on a compatible editor language model being available. Review generated content before applying it.
