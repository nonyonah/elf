# Elf documentation

This directory is the public Mintlify site; internal files in ../docs are not site content.

Preview: install the Mintlify CLI (`npm install -g mint`), then run `mint dev` from this directory.

In Mintlify, connect nonyonah/elf, branch beta/local-rc for preview (main after merge), with documentation directory `mintlify`. Alternatively copy this directory into a dedicated docs repository. Configure the production branch deliberately. The site is not deployed until the owner completes Mintlify account/GitHub authorization.
