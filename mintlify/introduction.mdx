---
title: "Meet Elf"
description: "Keep your code and Figma design system in sync."
---

Elf compares design tokens and managed components between your project and Figma. Review differences, sync supported changes, and receive Slack notifications while you work.

Choose your workflow:

- **Editor extension:** a native sidebar for Overview, Changes, Activity, and Manage in VS Code and compatible editors such as Cursor. See [editor installation](/vscode).
- **npm:** local onboarding, Settings, monitoring, and reviewed sync.
- **Local MCP:** connect a desktop coding assistant to inspect and edit an approved Figma document, including creating a design system from Markdown.

Elf Bridge runs inside Figma and performs document operations. Keep it open while using Elf. The local MCP does not provide a public URL for web-only assistants.

This is a beta. macOS with Node 22 has local acceptance evidence; other platforms and Node versions remain unverified. See [release notes](/releases).
