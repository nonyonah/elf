## Requirements

Use Node.js 22 and npm, a local project directory, and Figma Desktop. Install Elf Bridge when its Community listing is available; during beta, use the bundled development plugin.

## Start Elf

From your project directory:

```sh
npx elf-tokens@beta start
```

Complete onboarding: select the project and Figma file, then open Elf Bridge in that file. Paste the pairing code printed by Elf into the plugin. Pairing codes are single-use and expire; saved pairing credentials let the plugin reconnect later.

Follow the document-approval prompt. Strict verification uses your connected Figma account; plugin-only mode requires explicit approval of the current connection.

Start with a check. Review proposed changes before enabling automatic sync. Leave Elf running and Elf Bridge open.

The beta command requires the npm beta to have been published. If npm cannot find it, the release is not available yet.

Continue with [pairing](/pairing), [drift checks](/drift), or [VS Code](/vscode).
